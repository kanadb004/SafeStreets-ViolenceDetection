About SafeStreets

SafeStreets is an academic violence-detection prototype for a women's-safety CCTV context. Each 16 frame window is resized with letterboxing, passed through a frozen ImageNet MobileNetV2 for per-frame features, and scored by an LSTM head fine-tuned on AIRTLab. Both stages run as a single ONNX graph in ONNX Runtime on the CPU.

A score is a model probability, not a fact about the footage. The operating threshold was chosen on a validation split, and the model has known blind spots, recorded in the project's results and ethics documents. A human should review any alert before acting on it.
