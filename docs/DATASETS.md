# Datasets

Provenance, licence, citation, and access method for every source named in `docs/BUILD_PLAN.md`
§2. Generated by `safestreets/data/manifest.py`; label balance is read from
`data/manifests/splits.json` after `python scripts/fetch_data.py --dataset all` and
`python -m safestreets.data.manifest` have both run. See `docs/decisions/ADR-002-dataset-splits.md`
for how `group_id` and `split` are derived.

## RWF-2000

- **Access:** Kaggle, re-hosted mirror `rmilcb/rwf-2000-10fps` (`kaggle datasets download`).
  The canonical release requires emailing the authors for access; this mirror preserves the
  official `train/{Fight,NonFight}` / `val/{Fight,NonFight}` directory layout used for splitting.
- **Licence:** research/education use, per the original authors' release terms. No redistribution
  licence is stated on the Kaggle mirror; treat as research-only.
- **Citation:** M. Cheng, K. Cai, M. Li, "RWF-2000: An Open Large Scale Video Database for
  Violence Detection," ICPR 2020.
- **Clips fetched:** 2000 (1600 train / 400 val).
- **Label balance:** train 800 Fight / 800 NonFight; val 200 Fight / 200 NonFight.

## RLVS (Real Life Violence Situations)

- **Access:** Kaggle, `mohamedmustafa/real-life-violence-situations-dataset`.
- **Licence:** CC0 / public domain, as published on Kaggle.
- **Citation:** M. Soliman, M. Kamal, M. Nashed, Y. Mostafa, B. Chawky, D. Khattab, "Violence
  Recognition from Videos using Deep Learning Techniques," ICICIS 2019.
- **Clips fetched:** 1951 (this public re-hosting has slightly fewer than the nominal 1000+1000
  after removing a byte-identical duplicate copy nested in the zip — see
  `safestreets/data/download.py:fetch_rlvs`).
- **Label balance** (0 = NonViolence, 1 = Violence): train 700/704, val 119/155, test 132/141.
- **Note:** filenames (`V_<n>.mp4` / `NV_<n>.mp4`) carry no source-video id, so `group_id` is a
  content near-duplicate heuristic, not a filename parse. See ADR-002.

## AIRTLab

- **Access:** Kaggle, `tuannguyenhoang/airtlab`.
- **Licence:** "freely released for research and educational purposes" per the dataset's own
  `readme.md`.
- **Citation:** M. Bianculli, N. Falcionelli, P. Sernani, S. Tomassini, P. Contardo, M. Lombardi,
  A.F. Dragoni, "A dataset for automatic violence detection in videos," Data in Brief 33 (2020),
  doi:10.1016/j.dib.2020.106587.
- **Clips fetched:** 350 (60 non-violent + 115 violent, each shot from 2 cameras).
- **Label balance** (0 = non-violent, 1 = violent): train 86/156, val 16/44, test 18/30.
- **Note:** used again in Phase 7 for women-specific fine-tuning and 5-fold evaluation; the
  70/15/15 split built here is Phase 1's inventory split, not necessarily Phase 7's CV folds.

## UCF-Crime (subset)

- **Access:** two Kaggle sources, per BUILD_PLAN §3.1's instruction to fetch a 4-category-plus-
  Normal subset, never the full ~100 GB release:
  - `shashiprakash204/ucfcrimeminidataset` for Abuse, Assault, Fighting, and Normal (7 videos each,
    the mini dataset's full complement for those categories).
  - `bypktt/ucf-crimes` for Robbery, streamed file-by-file via `kaggle datasets download -f`
    (7 videos: `Robbery001`-`Robbery007`), since the mini dataset does not include this category.
- **Licence:** released by the original UCF Center for Research in Computer Vision for research
  use; re-hosted mirrors carry no additional licence terms.
- **Citation:** W. Sultani, C. Chen, M. Shah, "Real-world Anomaly Detection in Surveillance
  Videos," CVPR 2018.
- **Clips fetched:** 35 (7 Abuse, 7 Assault, 7 Fighting, 7 Robbery, 7 Normal).
- **Label balance** (0 = Normal, 1 = any crime category): train 3/21, val 3/3, test 1/4.
- **Note:** intentionally a small subset (BUILD_PLAN §3.1's ~0.8 GB cached budget for this
  source) feeding Phase 5's cross-dataset and frame-level evaluation, not the primary CNN-LSTM
  training pool.

## XD-Violence — SKIPPED (does not fit the disk budget)

- **What was needed:** the official pre-extracted I3D RGB+Flow features (never raw video — raw
  XD-Violence is comparable in size to raw UCF-Crime and does not fit the 44 GB disk budget,
  BUILD_PLAN §3.1). BUILD_PLAN §3.1 estimated this at ~4 GB.
- **Why it's skipped:** the project page (https://roc-ng.github.io/XD-Violence/) offers exactly
  two distributions:
  - **OneDrive:** `https://stuxidianeducn-my.sharepoint.com/:u:/g/personal/pengwu_stu_xidian_edu_cn/EYcpIgLj2TxKhlPlWcfjsZ4Bbe5tz7AbqH_eP3ZzM6Ul-Q` —
    a SharePoint "anyone with the link" share on the Xidian University tenant. It rejects a
    scripted `curl`/session download with a 403 and a forms-based-auth redirect (the anonymous-link
    handshake needs a real browser session), so this project fetched it manually in a browser to
    check the actual size: **`i3d-features.zip` is 38.3 GB**, nowhere near BUILD_PLAN's ~4 GB
    estimate and far beyond what the ~44 GB disk budget can absorb alongside the other four
    sources (§3.1's steady-state target is ~12 GB total). It was not downloaded onto this machine.
  - **Baidu Netdisk:** listed with extraction keyword `ou1n`; requires a Baidu account, which this
    project has no credentials for, and would carry the same 38.3 GB size problem regardless.
  - The estimate mismatch is likely because the release bundles both RGB *and* Flow I3D features
    (and possibly per-frame rather than per-segment features) rather than the smaller
    single-stream feature set BUILD_PLAN's §3.1 sizing assumed.
- **Decision:** permanently skip XD-Violence for this project. It fed only Phase 5's
  cross-dataset and frame-level AUC (a supplementary evaluation, not the CNN-LSTM training pool),
  so skipping it does not block any other phase. If a future session needs it, this would require
  either raising the disk budget (unlikely to be worthwhile for one dataset) or finding a
  same-content mirror that is genuinely feature-only and closer to the original size estimate.
- **Status:** `SKIPPED` (permanent) in `docs/PROGRESS.md`. `safestreets/data/download.py:fetch_xdviolence`
  raises `DatasetBlockedError` explaining the size, rather than silently skipping or fabricating a
  result.
- **Citation:** P. Wu et al., "Not only Look, but also Listen: Learning Multimodal Violence
  Detection under Weak Supervision," ECCV 2020.
